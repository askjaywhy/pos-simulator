Architecture

  • Database: SQLite (in-memory)
  • Frontend: Vanilla HTML/CSS/JS
  • Tests: Playwright

5-Minute Quick Start

Prerequisites

  • Node.js 14+
  • Python 3
  • Ports 3000 and 3001 available

Setup Steps

  1. Install backend:
    cd backend && npm install
  2. Start backend (Terminal 1):
    npm start
  3. Start frontend (Terminal 2):
    cd frontend && python3 -m http.server 3000
  4. Open browser:
    http://localhost:3000
  5. Test transaction:
    Card: 4111111111111111 Exp: 12/25 CVV: 123 Amount: 99.99

ISO 8583 Fields Reference

International standard for payment transaction messages

Field Name Type Length Category
0 Message Type Indicator (MTI) numeric 4 Control
2 Primary Account Number (PAN) numeric 19 Card
3 Processing Code numeric 6 Transaction
4 Amount, Transaction numeric 12 Transaction
11 System Trace Audit Number (STAN) numeric 6 Transaction
12 Time, Transaction (hhmmss) numeric 6 Transaction
13 Date, Transaction (MMDD) numeric 4 Transaction
39 Response Code numeric 2 Response
41 Card Acceptor Terminal ID alphanumeric 8 Terminal
42 Card Acceptor ID Code alphanumeric 15 Merchant

Plus 54+ additional fields covering Control, Card, Transaction, Security, Terminal, Institutional, and Account categories.
