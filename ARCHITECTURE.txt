│                            DATA FLOW EXAMPLE                                │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1. User enters card: 4111111111111111, Exp: 12/25, CVV: 123, Amount: 99.99│
│     └─ Frontend sends POST /api/transactions/process                       │
│                                                                             │
│  2. Server validates:                                                      │
│     ├─ Luhn checksum: PASS                                                 │
│     ├─ Exp format: MM/YY format: PASS                                      │
│     ├─ Check decline rules: Not in list → APPROVED                         │
│     └─ Generate response code: 00                                          │
│                                                                             │
│  3. Build EMV data:                                                        │
│     ├─ Add 9F06 (AID): 123456                                              │
│     ├─ Add 9F26 (Cryptogram): ABCDEF01                                    │
│     ├─ Add 95 (TVR): 0000000000                                            │
│     ├─ Add 9B (TSI): 0000                                                  │
│     └─ Generate TLV Hex: 9F06021234569F260...                             │
│                                                                             │
│  4. Build ISO 8583 message:                                                │
│     ├─ MTI: 0100 (Payment request)                                         │
│     ├─ Field 2 (PAN): 4111111111111111                                     │
│     ├─ Field 4 (Amount): 009999 (in cents)                                 │
│     ├─ Field 11 (STAN): 123456 (unique)                                    │
│     ├─ Field 39 (Response): 00 (approved)                                  │
│     └─ Generate message Hex: 0100...                                       │
│                                                                             │
│  5. Store in database:                                                     │
│     ├─ Transaction ID, timestamp, card masked                              │
│     ├─ EMV tags as JSON: {"9F06": {...}, "9F26": {...}, ...}              │
│     ├─ ISO 8583 as JSON: {"0": "0100", "2": "4111...", ...}               │
│     └─ Save to SQLite                                                      │
│                                                                             │
│  6. Return response to browser:                                            │
│     ├─ success: true                                                       │
│     ├─ status: "APPROVED"                                                  │
│     ├─ response_code: "00"                                                 │
│     ├─ emv: { tags: {...}, tlv_hex: "..." }                               │
│     ├─ iso8583: { mti: "0100", fields: {...}, hex_message: "..." }        │
│     └─ auth_code, transaction_id, timestamp, etc.                         │
│                                                                             │
│  7. Frontend displays:                                                     │
│     ├─ Summary tab: Transaction details                                    │
│     ├─ EMV Tags tab: 25+ tags with hex values                              │
│     ├─ ISO 8583 tab: 64+ fields with values                                │
│     └─ Copy buttons for hex data                                           │
